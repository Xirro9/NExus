Smart Turn v3.2 (pipecat-ai): semantic end-of-turn classifier — audio in, probability the user finished their thought. License BSD-2-Clause for code and weights ('truly open'). Model: ~8M params (Whisper-Tiny backbone), 8MB int8 CPU ONNX / 32MB fp32 GPU ONNX, 23 languages. Runs on CPU: 10-12ms modern CPU, ~60ms cheap AWS vCPU, 3.3ms L40S (incl. preprocessing). Input: 16kHz mono f32, up to 8s context, zero-pad at beginning. Official >8s policy (README): truncate from the BEGINNING to shorten audio to ~8 seconds; if additional speech is detected, re-run Smart Turn on the ENTIRE turn recording. Designed to run only during acoustic silence (e.g. Silero VAD gates it). Standalone usage: repo ships inference.py/predict.py using raw onnxruntime — portable to Rust ort crate without Pipecat. Weakness on tiny clips (<2s like 'yes'/'stop') — resolve those as complete turns by rule.
