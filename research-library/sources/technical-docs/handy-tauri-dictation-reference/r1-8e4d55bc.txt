Handy: free/libre dictation app, Tauri 2, MIT, 38.2k stars, very active. Architecture (from Cargo.toml v0.10.0 + README): audio capture is 100% Rust-side via handy-recorder 0.1 ('Simple cross-platform microphone capture for Rust. Extracted from Handy' — opens the mic at whatever format the OS provides, 16kHz mono f32, official push_to_talk example; underlying handy-cpal = cpal fork with pipewire/pulseaudio features fixing PulseAudio stalls). NOTHING audio goes through the webview. VAD: Silero Rust-side. STT: transcribe-cpp 0.4 (GGML/GGUF; whisper .bin models incl ggml-large-v3-turbo.bin 1600MB and ggml-large-v3-q5_0.bin 1100MB, plus parakeet-unified-en-0.6b-Q8_0.gguf 731MB); Linux backends = dynamic-backends + Vulkan (NOT CUDA). Playback: rodio + symphonia (decode), never the webview. Models downloaded via hf-hub (cjpais fork, cancellable) into app-data models/ dir. Hotkeys: tauri-plugin-global-shortcut + rdev; single-instance plugin for CLI control (--toggle-transcription). Maintains three WebKitGTK renderer workarounds incl per-version WEBKIT_DMABUF_RENDERER and dropped SIGUSR1 listening because WebKitGTK uses it for JS GC (phantom recordings, issue #1660).
